# Cadastro Completo de Locação

Formulário digital preenchível da Rezuski Imóveis, em página única (HTML, CSS e JavaScript, sem dependências).

## O que faz

- Reproduz a ficha de cadastro de locação em formato A4.
- Campos com máscara (CPF, RG, telefone, valores em R$, data, agência e conta).
- Campo de assinatura e nome do contratante ao final.
- Botão "Baixar PDF" (A4) e botão "Imprimir".
- O rascunho fica salvo no navegador de quem preenche. Nenhum dado é enviado para servidor.

## Como publicar na Vercel

1. Suba estes arquivos para um repositório no GitHub.
2. Na Vercel, clique em Add New > Project e importe o repositório.
3. Em Framework Preset deixe "Other". Não precisa de Build Command nem de Output Directory.
4. Clique em Deploy.

## Como atualizar

Troque o `index.html` no repositório. A Vercel publica a nova versão automaticamente.
